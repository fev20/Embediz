01

카메라의 새로운 실행 환경

화이트햇 스쿨 4기 2차 교육과정에서 진행한 Embediz 프로젝트입니다. JOOAN 홈캠의 하드웨어와 펌웨어를 분석하고, 기존에 제공되지 않던 외부 프로그램인 DOOM을 기기에서 실행했습니다.

화면과 입력, 파일과 타이머를 함께 사용하는 DOOM을 포팅하며 단순한 파일 변경을 넘어 기기의 실행 환경을 이해하고 연결하는 과정을 경험했습니다.

02

펌웨어에서 시작한 네 단계

  1. 01

    펌웨어 획득

    공개 펌웨어와 실장비를 대상으로 펌웨어를 확보하고 분석의 출발점을 마련했습니다.

  2. 02

    구조와 흐름 분석

    파티션과 파일시스템을 구분하고 부팅 스크립트, GoAhead, 프로그램의 실행 조건을 추적했습니다.

  3. 03

    DOOM 포팅

    MIPS 환경에 맞춰 크로스컴파일하고, WebSocket으로 화면 출력과 키 입력 경로를 구현했습니다.

  4. 04

    적용과 검증

    수정 펌웨어를 실기기에 적용한 후 웹 버튼을 통한 실행과 브라우저의 게임 화면 갱신을 확인했습니다.

03

게임은 기기에서 실행됩니다.

브라우저는 화면과 입력을 연결하는 역할을 맡습니다. 게임 자체는 홈캠의 MIPS CPU에서 동작하며, 카메라의 원래 영상 스트림과는 별도의 경로로 화면을 전달합니다.

실행 파일과 WAD는 SD 카드에 배치했습니다. 최종 시연에서는 웹 로그인 화면의 Reset 버튼을 실행 계기로 사용하고, 게임 페이지 이동을 함께 연결했습니다.

04

실기기에서 확인한 결과

✓ VERIFIED

홈캠 CPU에서 실행

수정한 펌웨어와 크로스컴파일한 DOOM을 실제 JOOAN 홈캠에 적용했습니다.

✓ VERIFIED

브라우저 화면 갱신

WebSocket으로 전달받은 시작 화면과 게임 진행 중 장면 갱신을 확인했습니다.

✓ IMPLEMENTED

화면과 입력 연결

Canvas 출력과 키 이벤트 전송, 기기 입력 큐를 하나의 흐름으로 연결했습니다.

✓ VERIFIED

웹 버튼으로 시작

Reset 버튼에서 DOOM 실행과 게임 페이지 이동으로 이어지는 동작을 확인했습니다.

검증 범위를 함께 기록합니다.

대상은 Secure Boot가 적용되지 않은 기기입니다. 최종 WebSocket 구성의 정확한 fps와 장시간 실행 안정성은 검증하지 않았으며, DOOM 화면은 홈캠의 기본 앱이 아닌 별도 브라우저 페이지에 표시됩니다.
