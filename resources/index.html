자주 묻는 질문

1~2월에 글리칭과 DOOM 포팅까지 진행하나요?

1~2월은 Secure Boot 적용 홈캠을 분석하는 프로젝트입니다. 글리칭 적용과 DOOM 포팅은 그 분석 결과를 바탕으로 여름방학에 진행할 별도 프로젝트로 잠정 계획하고 있습니다. 정확한 여름 일정과 세부 방법은 아직 정하지 않았습니다.

DOOM은 브라우저에서 실행되나요?

DOOM 자체는 JOOAN 홈캠의 MIPS CPU에서 실행됩니다. 브라우저는 WebSocket으로 받은 화면을 Canvas에 표시하고 키 입력을 기기로 전달합니다.

카메라의 기본 앱에서도 DOOM을 볼 수 있나요?

현재 구현은 별도 브라우저 페이지로 화면을 전달합니다. 카메라 센서와 인코더를 거치는 기본 영상 경로에 DOOM 화면을 넣는 방식은 구현 결과에 포함되지 않습니다.

Embediz2는 화이트햇 스쿨의 다음 교육과정인가요?

아닙니다. 기존 Embediz는 화이트햇 스쿨 4기 2차 교육과정에서 진행한 프로젝트이며, Embediz2는 수료 후 자발적으로 준비하는 후속 프로젝트입니다.

소스 코드와 전체 보고서는 어디서 볼 수 있나요?

DOOM 포팅 프로젝트 상세 페이지 상단의 GitHub 저장소에서 공개된 소스 코드와 자료를 확인할 수 있습니다. 이 사이트에서는 프로젝트 요약과 최종 시연 영상을 제공합니다. 후속 프로젝트의 자료 공개 범위는 추후 정리합니다.

현재 사이트에서 직접 DOOM을 플레이할 수 있나요?

이 사이트는 연구 소개와 기록을 위한 페이지입니다. 실제 카메라에 접속하는 플레이 기능은 제공하지 않으며, 실기기 동작은 시연 영상으로 확인할 수 있습니다.
