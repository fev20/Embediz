펌웨어 분석 / RESEARCH NOTE

펌웨어 이미지에서 실행 환경까지

파티션, 파일시스템, 부팅 스크립트를 연결해 DOOM이 실행될 자리를 찾는 과정.

2026.10.25Embediz
01

시작점은 펌웨어의 구조

펌웨어 이미지에서 커널과 파일시스템의 위치를 식별하고, 기기의 mtdparts 선언과 대조해 파티션 구성을 확인했습니다. 매직 바이트로 찾은 위치와 기기에서 사용하는 경계를 함께 살펴보는 방식입니다.

02

각 파일시스템의 역할

rootfs와 appfs는 읽기 전용 SquashFS, config는 쓰기 가능한 JFFS2로 구분했습니다. 프로그램을 배치할 위치와 실행 중 사용할 공간을 정하기 위해 읽기·쓰기 가능 여부와 SD 카드 마운트 지점을 확인했습니다.

03

전원이 켜진 뒤의 흐름

linuxrc에서 BusyBox init, inittab, rcS, startapp으로 이어지는 호출 관계를 추적했습니다. 부팅 스크립트, 웹 서버 GoAhead와 카메라 프로그램이 어떤 순서와 조건으로 실행되는지 연결해 실행 환경을 파악했습니다.

04

포팅을 위한 조건 확인

바이너리 형식, 아키텍처, 엔디언과 라이브러리 의존성을 조사해 크로스컴파일 환경을 구성했습니다. 실제 기기에 맞는 바이너리를 만드는 일과 파일 배치·실행 조건을 확인하는 일을 함께 진행했습니다.
